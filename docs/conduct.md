# Conduct and reporting concerns

The existing [organization Code of Conduct](https://github.com/Pick-Your-AI/.github/blob/main/CODE_OF_CONDUCT.md) applies. It asks contributors to be respectful, honest about evidence, patient with newcomers and free from harassment, threats, unwelcome attention and publication of private information.

Use its existing reporting instructions: GitHub’s Report content option or an organization owner's GitHub profile contact route. Check the destination and visibility before sharing sensitive details. This hub has no confidential reporting form or new private mailbox, and cannot guarantee the confidentiality or availability of a profile contact channel. Do not post sensitive allegations in applications or the public Project. Where possible, reports should be handled by an owner who is not involved. Owners retain enforcement authority under the existing policy; a volunteer reviewer is not automatically a conduct investigator.

For security concerns, use the affected repository's published security policy. Do not publish vulnerability details in volunteer intake. This document links existing procedures; it does not create a legal privacy, employment or safeguarding policy.
